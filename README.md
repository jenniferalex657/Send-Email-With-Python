**Python Email Sender**  
This Python script sends an email using Gmail and logs the status.  
   
Setup:  
	1.	Replace sender, receiver, and password with your Gmail account details.  
	•	Generate an App Password in your Google account if using 2FA.  
	2.	Modify subject and body as needed.  
   
How to Run:  
python send_email.py  
   
Logging:  
	•	Logs are saved in email_log.log with success or error messages.
